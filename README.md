# USBSilentCopy 🚀

یک نرم‌افزار سبک، قابل حمل (Portable) و قابل اعتماد برای ویندوز جهت **پشتیبان‌گیری خودکار و هوشمند از حافظه‌های فلش USB و درایوهای Removable**.

---

## ویژگی‌های کلیدی (Key Features)

* **⚡ شناسایی خودکار درایوهای USB (Auto Detection):** تشخیص بلادرنگ اتصال و جداسازی فلش مموری‌ها از طریق رویدادهای هسته ویندوز (`WM_DEVICECHANGE`) و WMI بدون نیاز به اسکن‌های مکرر و سنگین.
* **🤫 عملکرد کاملاً خاموش و پس‌زمینه (Silent Mode):** در حالت سایلنت، برنامه بدون هیچ‌گونه آیکون سینی (Tray)، اعلان یا پنجره مزاحم اجرا شده و صرفاً از طریق Task Manager قابل مدیریت است.
* **🔄 پشتیبان‌گیری افزایشی (Incremental Backup):** تشخیص فایل‌های جدید یا تغییریافته بر اساس حجم، زمان ویرایش و مقایسه اختیاری هش الگوریتم SHA256 برای جلوگیری از کپی فایل‌های تکراری.
* **🎛️ سیستم پروفایل اختصاصی درایوها (USB Profiles):** امکان شناسایی هر حافظه بر اساس شماره سریال سخت‌افزاری و ذخیره تنظیمات مجزا (مانند مسیر مقصد اختصاصی، فیلترها و محدودیت سرعت).
* **🧹 فیلترهای پیشرفته فایل و پوشه (Advanced Filters):** فیلتر بر اساس دسته‌بندی (ویدیو، اسناد، تصاویر، آرشیو، فایل‌های اجرایی)، پسوندها، اندازه فایل، بازه تاریخی، و نادیده‌گرفتن خودکار پوشه‌های سیستمی نظیر `$RECYCLE.BIN`.
* **⏸️ توقف و ادامه سریع با میانبر سراسری:** امکان توقف موقت و ادامه پشتیبان‌گیری با کلید میانبر سراسری و بی‌صدای `Ctrl + O + P`.
* **🛡️ پایش فضای ذخیره‌سازی مقصد (Disk Space Protection):** بررسی مداوم فضای خالی هارددیسک و توقف ایمن عملیات در صورت رسیدن به حداقل فضای مجاز برای جلوگیری از خرابی فایل‌ها.
* **📊 تاریخچه جامع و خروجی داده‌ها:** ثبت دقیق مشخصات هر سشن پشتیبان‌گیری با امکان جستجو، فیلتر و دریافت خروجی با فرمت‌های استاندارد `CSV` و `JSON`.
* **📜 سیستم لاگ‌گیری چرخشی (Log Rotation):** ثبت دقیق وقایع سیستم، خطاها، عملکرد هر دستگاه با چرخش خودکار فایل‌های گزارش جهت جلوگیری از پر شدن دیسک.
* **💼 نسخه پرتابل تک‌فایلی (Single-File Portable):** بدون نیاز به نصب یا دسترسی Administrator، آماده اجرا به محض دانلود.

## نحوه اجرا و سوئیچ‌های خط فرمان (Command-line Arguments)

فایل `USBSilentCopy.exe` را می‌توانید به راحتی اجرا کنید:

```powershell
# اجرای عادی (بر اساس تنظیمات config.json؛ در صورت غیرفعال بودن silentMode در سینی ویندوز باز می‌شود)
.\USBSilentCopy.exe

# اجبار به اجرای در حالت کاملاً خاموش و مخفی
.\USBSilentCopy.exe --silent

# اجبار به باز شدن داشبورد مدیریت و تنظیمات
.\USBSilentCopy.exe --ui

# استفاده از یک فایل تنظیمات دلخواه
.\USBSilentCopy.exe --config "D:\MyConfigs\custom_config.json"
```

## کلید میانبر سراسری

* **`Ctrl + O + P`**: با فشردن همزمان این سه کلید، عملیات پشتیبان‌گیری بدون هیچ‌گونه نمایش پنجره یا اعلان صوتی، متوقف موقت (Pause) یا ادامه (Resume) می‌یابد.

## راهنمای ساخت و کامپایل پروژه (Build & Test)

برای اجرای آزمون‌ها و ساخت نسخه Release جدید، می‌توانید از دستورات زیر یا اسکریپت `build.ps1` استفاده کنید:

```powershell
# ۱. اجرای تمام تست‌های خودکار
dotnet test tests/USBSilentCopy.Tests.csproj

# ۲. ساخت نسخه پرتابل تک‌فایل (Portable Single-File)
dotnet publish src/USBSilentCopy.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

این نرم‌افزار صرفاً یک ابزار کاربردی و قانونی جهت حفظ و نگهداری فایل‌های شخصی کاربران است:
- هیچ‌گونه دور زدن تدابیر امنیتی ویندوز، تزریق پروسس یا رفتار مشابه بدافزار ندارد.
